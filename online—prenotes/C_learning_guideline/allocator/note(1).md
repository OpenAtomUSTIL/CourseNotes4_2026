## 2. 内存分配 

### 2.1 堆和栈
C 语言中既有关键字，也有标准库提供的函数。例如 if、return 是关键字，而 printf、malloc 是标准库函数。那各位不知道有没有想过函数运行在什么地方。这里之前也有提过 
各位后面会学到一种数据结构叫`stack`栈,这种数据结构在内存当中很常用。 在内存当中我们也会有对应的应用，
函数调用所需的部分信息和局部变量通常存储在栈上


堆是程序运行时用于动态内存分配的内存区域。通过 malloc 申请的内存通常来自堆，申请后可以一直使用，直到调用 free 释放。
程序结束时，操作系统通常会回收进程占用的内存。栈空间通常有相对明确的大小限制，而堆可以用于管理更大规模的动态内存。具体容量取决于运行环境。

### 2.2 malloc 
这是`C`当中申请内存的主要手段 
函数的原型就是 
```c
void *malloc(size_t size);
```
malloc函数的参数是你需要申请的内存有多大，然后因为类型是`void *`即 无类型，表示通用对象指针类型。
在 C 语言中，void * 可以隐式转换成其他对象指针类型，不需要强制类型转换。
这个返回值可以转换成任意类型。
那我们其实按照这个来写就可以了。即 
- 准备好你要分配的指针
- 想好你想分配的内存有多大 
- 转换成你需要的类型

达成上述三点就可以使用内存分配了。

这个本身不是一个关键字，而是语言本身内置的一个==函数==。
因此你可以像任意的一个函数来操作它。所以如果没太理解不一定是这个部分的问题，也可能是函数部分的问题。

那什么是malloc呢 作用就是给你想要分配的地址部分分配你所希望的大小的内存。这部分内容会是从哪分配的呢，从堆。
因为我们说过，栈本身很小，并且主要负责管理程序运行时候入栈和出栈。堆上会有很多闲置内存，可供分配。

怎么用呢 
我们之前有提到过，数组名字 = 数组地址当中的首地址。因此你可以用数组名字或者一个指针来表示一个数组的地址。
那我们设想一个场景。当你的数组的长度需要用户输入的时候，那你肯定不能用一个定长的数组来进行表示，因此你需要
用`malloc`来根据用户输入的长度来进行动态的分配，为什么动态呢，因为后续还会有其他的函数来更改。
```c 
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

int main(void) {
    size_t size;

    printf("请输入数组长度：");

    if (scanf("%zu", &size) != 1 || size == 0) {
        printf("输入无效\n");
        return 1;
    }

    if (size > SIZE_MAX / sizeof(int)) {
        printf("数组过大\n");
        return 1;
    }

    int *p = malloc(size * sizeof(*p));

    if (p == NULL) {
        printf("内存分配失败\n");
        return 1;
    }

    for (size_t i = 0; i < size; i++) {
        p[i] = (int)(i % 100) * 10;
    }

    for (size_t i = 0; i < size; i++) {
        printf("p[%zu] = %d\n", i, p[i]);
    }

    free(p);
    p = NULL;

    return 0;
}
```

## 文件操作 

C当中的文件操作是通过操作句柄来实现的，通过 <stdio.h> 中定义的`FILE`文件流类型，来对任意的文件进行操作。
本质上是通过一个这个`FILE`的指针来调用对应内部实现好了的一些函数或者说方法。

基本步骤就是打开文件，选择以什么模式打开，这个说穿了就是想对文件进行什么操作，读还是写还是追加。
然后执行完操作之后关闭你打开的文件即可。

```c
#include <stdio.h>

int main(){
    FILE * fp = fopen("newfile.file","w");// 创建一个新的文件，以写的权限打开 
    // 注意 这里 这个新建的文件完全是我虚构出来的，存不存在我不知道，我只是想创建一个这样的文件。
    if (fp == NULL) {
        printf("erorr open file !\n");
        return 1;
    }
    fprintf(fp,"hello newfile!");// 如果是写权限可以往文件当中写入，传入一个句柄和一个想要写入的内容。
    fclose(fp);// 关闭文件
}
```

这里如果执行的话会创建一个里面写这hello newfile！的文件。 也可以尝试其他的模式 比如 `r` `a` 或者 其他模式。
