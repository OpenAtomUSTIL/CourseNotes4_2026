## 题目描述

McCarthy 是一个很出名的计算机科学家。有一天，他研究出一个有趣（无聊）的函数，叫"f91"。函数功能如下：

- 如果 n ≤ 100，则 f91(n) = f91(f91(n + 11))
- 如果 n ≥ 101，则 f91(n) = n - 10

然而 McCarthy 的电脑坏了，所以求助你来编一个程序来研究这个神奇的函数。

## 输入格式

输入包含多组测试数据，每行一个整数 n（n = 0 时结束）。

## 输出格式

对于每个输入的 n，输出一行：`f91(n) = 结果`（等号两边有空格）

## 输入输出样例

**输入 #1**
```
500
91
0
```

**输出 #1**
```
f91(500) = 490
f91(91) = 91
```

## 解决方案

### 方案一：递归

使用递归函数直接实现题目描述的规则。

```c
#include<stdio.h>

int f91(int n)
{
    if(n <= 100) return f91(f91(n + 11));
    else return n - 10;
}

int main()
{
    int m;
    while(scanf("%d", &m) == 1 && m != 0)  // 多组输入
        printf("f91(%d) = %d\n", m, f91(m));  // 格式输出
    return 0;
}
```

### 方案二：数学证明

通过数学证明可以发现 f91 函数的神奇性质：

**已知：**
```
f(x) = {
    f(f(x + 11)),  x ≤ 100
    x - 10,        x ≥ 101
}
```

**求证：**
```
f(x) = {
    91,    x ≤ 100
    x - 10, x ≥ 101
}
```

**证明：**

1. 若 x ≥ 101，直接返回 x - 10
2. 若 x ≤ 100，设 x = 11k + m（k ∈ N, m ∈ N ∩ [0, 10]）

经过数学推导可以证明，无论 k, m 为何值，均满足：
- 当 x ≤ 100 时，f(x) = 91
- 当 x ≥ 101 时，f(x) = x - 10

**原理解释：**
当 x ≤ 100 时，f(x) 经过数次操作必然会变成 f^n(y)（91 ≤ y ≤ 100），而经过 n 轮这样的操作后必然会得到 f(x) = f^n(91) = f(91) = 91。

### 方案三：简化代码

基于数学证明，可以直接使用条件表达式实现：

```c
#include<stdio.h>

int f91(int x)
{
    return x <= 100 ? 91 : x - 10;
}

int main()
{
    int n;
    scanf("%d", &n);
    while(n)
    {
        printf("f91(%d) = %d\n", n, f91(n));
        scanf("%d", &n);
    }
    return 0;
}
```
