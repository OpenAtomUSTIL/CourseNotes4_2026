## 题目描述

How many real roots does the equation $\sin(a\pi x)=x^2$ have?

## 输入格式

Enter an $a$

## 输出格式

Output a $num$ to indicate the number.

## 输入输出样例

### 输入 #1

```text
2020
```

### 输出 #1

```text
4040
```

## 说明/提示

`a`, `num` should preferably be of type `long long`.
