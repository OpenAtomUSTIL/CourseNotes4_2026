# P1914 小书童——凯撒密码 题解

## 题意

给定 $n$（$1 \le n \le 26$）和一个由不超过 50 个小写字母组成的原文字符串。密码由原文字符串中每个字母向后移动 $n$ 位得到，`z` 的下一个是 `a`（循环）。求密码。

## 思路

Caesar 移位。对每个字符 $c$：新字符为 `'a' + (c - 'a' + n) % 26`。取模自动处理循环。

## 复杂度

- 时间 $O(|s|)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>

int main(void) {
    int n;
    char s[60];
    scanf("%d %s", &n, s);
    for (int i = 0; s[i]; i++)
        s[i] = 'a' + (s[i] - 'a' + n) % 26;
    printf("%s\n", s);
    return 0;
}
```
