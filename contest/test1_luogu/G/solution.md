# P1534 不高兴的津津（升级版） 题解

## 题意

津津未来 $n$ 天，每天上学 $a$ 小时、课外补习 $b$ 小时。与 NOIP2004 原版不同：她的不高兴（或高兴）**会持续到第二天**。每天的不高兴程度 = 昨天不高兴程度 $+\ (a+b-8)$。求 $n$ 天结束后不高兴程度的**总和**。

## 思路

直接递推模拟。维护当前不高兴程度 `un`（可为负数，表示高兴），每天：

1. `un += a + b - 8`;
2. `sum += un`。

验证样例：七天 `un` 依次为 $0,0,1,1,2,-2,-4$，累加得 $0+0+1+1+2-2-4=-2$ ✓。

## 复杂度

- 时间 $O(n)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);
    long long un = 0, sum = 0;
    for (int i = 0; i < n; i++) {
        int a, b;
        scanf("%d %d", &a, &b);
        un += a + b - 8;
        sum += un;
    }
    printf("%lld\n", sum);
    return 0;
}
```
