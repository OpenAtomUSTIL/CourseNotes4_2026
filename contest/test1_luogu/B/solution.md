# B3763 [语言月赛202305] 团体程序设计天梯赛 题解

## 题意

按 基础级(8 题) → 进阶级(4 题) → 登顶级(3 题) 的顺序给出某选手 15 题的得分，计算有效得分：

- 基础题总分 $\ge 80$ 时，进阶部分得分才有效；
- 进阶题总分 $\ge 40$ 时，登顶部分得分才有效。

**注意题目中的"超过"指大于等于。**

## 思路

纯模拟。分别求三部分分数和 $s_1,s_2,s_3$，然后：

- 答案先等于 $s_1$;
- 若 $s_1 \ge 80$，答案加上 $s_2$;若此时 $s_2 \ge 40$，再加上 $s_3$。

验证样例 1：基础 $100 \ge 80$，进阶 $91 \ge 40$，总分 $100+91+1=192$ ✓。
样例 2：基础 $2 < 80$，只算基础，答案 $2$ ✓。

## 复杂度

- 时间 $O(1)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>

int main(void) {
    int s1 = 0, s2 = 0, s3 = 0, x;
    for (int i = 0; i < 8; i++) { scanf("%d", &x); s1 += x; }
    for (int i = 0; i < 4; i++) { scanf("%d", &x); s2 += x; }
    for (int i = 0; i < 3; i++) { scanf("%d", &x); s3 += x; }

    int ans = s1;
    if (s1 >= 80) {
        ans += s2;
        if (s2 >= 40) ans += s3;
    }
    printf("%d\n", ans);
    return 0;
}
```
