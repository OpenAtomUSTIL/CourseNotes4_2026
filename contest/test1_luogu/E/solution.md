# P1033 [NOIP 2002 提高组] 自由落体 题解

## 题意

高为 $H$ 的天花板上有 $n$ 个小球，位置分别为 $x=0,1,\cdots,n-1$，做自由落体，下落距离 $d = 0.5 \times g \times t^2 = 5t^2$（$g=10$）。地面上有一辆小车：长 $L$、高 $K$，近端距原点 $S_1$，以速度 $V$ **向原点方向**行驶（位置随时间减小）。小车与所有小球同时开始运动。当小球高度在 $K$ 到 $0$ 之间、且水平位置落在小车所占区间 $[\,d,\ d+L\,]$ 内（误差 $\le 0.0001$）时，小球被接受；落到地面后不能被接受。求能接受多少个小球。

## 思路

对位于 $x=i$ 的小球，只需考察它**下落到车顶高度 $K$ 到落地**这段时间里，车是否从它"身下"经过：

- 落到高度 $K$ 的时刻：$t_1 = \sqrt{(H-K)/5}$，此时车近端位置 $d_1 = S_1 - V t_1$;
- 落地的时刻：$t_2 = \sqrt{H/5}$，此时车近端位置 $d_2 = S_1 - V t_2$（$d_2 < d_1$)。

小车向原点行驶，在这段时间内车近端从 $d_1$ 移动到 $d_2$，车扫过的水平区间为 $[\,d_2,\ d_1+L\,]$。小球被接受当且仅当

$$d_2 < i + \varepsilon \quad\text{且}\quad i - \varepsilon \le d_1 + L,\qquad \varepsilon = 10^{-4}.$$

验证样例：$H=5,S_1=9,V=5,L=2.5,K=1.8$，$t_1=0.8,\ d_1=5$;$t_2=1,\ d_2=4$。条件即 $4 < i+10^{-4}$ 且 $i-10^{-4} \le 7.5$，只有 $i=4$ 满足，答案 $1$ ✓。

$t_1,t_2,d_1,d_2$ 对所有小球相同，只需算一次；然后 $O(n)$ 逐个判断。

## 复杂度

- 时间 $O(n)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>
#include <math.h>

#define EPS 1e-4

int main(void) {
    double H, S1, V, L, K;
    int n;
    scanf("%lf %lf %lf %lf %lf %d", &H, &S1, &V, &L, &K, &n);

    double t1 = sqrt((H - K) / 5.0);  // 落到车顶高度 K 的时刻
    double t2 = sqrt(H / 5.0);        // 落地的时刻
    double d1 = S1 - V * t1;          // t1 时刻车近端距原点的距离
    double d2 = S1 - V * t2;          // t2 时刻车近端距原点的距离

    int ans = 0;
    for (int i = 0; i < n; i++)
        if (d2 < i + EPS && i - EPS <= d1 + L) ans++;
    printf("%d\n", ans);
    return 0;
}
```
