# U305098 数学的重要1 题解

## 题意

求方程 $\sin(a\pi x) = x^2$ 的实根个数。输入一个整数 $a$（用 `long long`）。样例：$a = 2020$ 时答案为 $4040$。

## 思路

**结论：答案为 $2a$**（$a$ 为正整数时）。

推导：

1. **根只能出现在 $\sin(a\pi x) \ge 0$ 且 $|x| \le 1$ 的地方。** 因为 $x^2 \ge 0$，而 $|x| > 1$ 时 $x^2 > 1 \ge \sin(a\pi x)$，不可能相等；$x = \pm 1$ 时 $\sin(\pm a\pi)=0 \ne 1$，也不是根。

2. **$x = 0$ 恒为一个根**（两边都为 0）。

3. **正半轴**：$\sin(a\pi x) \ge 0$ 的区间为"拱" $I_k = [\frac{2k}{a}, \frac{2k+1}{a}]$，$k = 0, 1, \cdots$（直到区间超出 1）。每个拱上 $\sin$ 从 0 升到 1 再降回 0，而 $x^2$ 单调上升：拱两端 $\sin = 0 < x^2$，拱顶处 $\sin = 1 > x^2$（拱内 $x < 1$），所以**每个完整拱恰好贡献 2 个交点**。最左边的拱 $I_0 = [0, \frac1a]$ 的左端点就是 $x = 0$ 根本身，它贡献 $x=0$ 加一个内部交点。
   - $a = 2m$：共 $m$ 个拱 $\Rightarrow 2m$ 个正根（含 $x=0$）；
   - $a = 2m+1$：共 $m+1$ 个拱 $\Rightarrow 2m+2$ 个正根（含 $x=0$）。

4. **负半轴**：$\sin(a\pi x) \ge 0$ 的区间为 $[\!-\frac{2k}{a}, -\frac{2k-1}{a}]$，$k = 1, 2, \cdots$，同样每个完整拱 2 个交点。
   - $a = 2m$：共 $m$ 个拱 $\Rightarrow 2m$ 个负根；
   - $a = 2m+1$：共 $m$ 个拱 $\Rightarrow 2m$ 个负根。

5. **合计**：$a=2m$ 时 $2m + 2m = 4m = 2a$;$a=2m+1$ 时 $(2m+2) + 2m = 4m+2 = 2a$。即恒有

$$\text{实根个数} = 2a.$$

验证样例：$a = 2020 \Rightarrow 2a = 4040$ ✓。

因此代码只需读入 $a$ 输出 $2a$。若 $a$ 可能为负，$\sin(a\pi x)$ 关于 $a$ 是奇函数，答案只与 $|a|$ 有关；$a = 0$ 时方程变为 $0 = x^2$，仅有 $x = 0$ 一个根。

## 复杂度

- 时间 $O(1)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>

int main(void) {
    long long a;
    scanf("%lld", &a);
    if (a < 0) a = -a;
    if (a == 0) printf("1\n");   // sin(0) = x^2 只有 x = 0
    else        printf("%lld\n", 2 * a);
    return 0;
}
```
