# P1085 [NOIP 2004 普及组] 不高兴的津津 题解

## 题意

给出津津周一到周日每天在校时间 $a$ 和妈妈安排的时间 $b$（均为小于 10 的非负整数）。若一天上课总时间超过 8 小时（即 $a+b > 8$）她就不高兴，不高兴程度为 $a+b-8$；不高兴不会持续到第二天。输出最不高兴的是周几（$1\sim 7$）；若一周都不会不高兴输出 $0$。程度并列时输出最靠前的一天。

## 思路

模拟 7 天，每天计算程度 $t = a+b-8$。严格大于 8 小时才不高兴，即只统计 $t \ge 1$ 的天。用 `best` 记录最大程度，`ans` 记录对应星期；因为只在 $t$ 严格更大时更新，`best` 初值 0 自然保证"并列取最早"和"全不高兴输出 0"。

验证样例：七天程度分别为 $0,0,1,0,1,-4,-2$，最大值 1 首次出现在周三，输出 3 ✓。

## 复杂度

- 时间 $O(1)$,空间 $O(1)$。

## 参考代码（C)

```c
#include <stdio.h>

int main(void) {
    int best = 0, ans = 0;
    for (int d = 1; d <= 7; d++) {
        int a, b;
        scanf("%d %d", &a, &b);
        int t = a + b - 8;
        if (t > best) { best = t; ans = d; }
    }
    printf("%d\n", ans);
    return 0;
}
```
