# 笔记整理
项目当中内容是学长们上课的各种笔记概要和课上的源代码

## 1. 目录概要 

1. `course`目录当中是机房上课当中学长们写的一些笔记和概要 
2. `answer`目录当中是课上涉及到的题目和题解 
3. `online-prenotes`是前代负责人自己写的笔记和网课的笔记
4. 笔记的文件夹以笔记内容概要或者上课时间命名，大家按需查询即可
5. 如果想要先了解如何使用和查看或者怎么在本地用到这些内容的话，可以先去学习一下`git`的使用

有问题可以先看一下README 然后按照需要查看文档内容即可
