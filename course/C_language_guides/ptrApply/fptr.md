## 数组指针和指针数组

字面意义上就是指向数组的指针，也就是这个指针变量的地址对应的东西
是 数组。
这里不知道各位是否还记得 数组的特性就是在内存当中的存储是连续的
因此.指针实际上会指向这个数组的首地址，也就是数组第一个元素的的
位置.
```C 
#include <stdio.h>

int main(){
    int arr[4] = {1,2,3,4};
    int (*p)[4] = arr; // 这个是指向 arr 这个数组的指针 后面长度是数组内元素数量
    int a1 = 1,a2 = 2, a3 = 3;
    // 这个就是指针数组了，换句话讲，数组内所有的元素都是指针。这样你想要遍历就直接用指针去指向下一个位置即可
    int *pArr[3] = {&a1,&a2,&a3}; 
}
```

### 指针来遍历数组 
- 由于数组在内存当中的存储形式是连续的也就是在内存上是连续的，
- 同时 小学三年级的小朋友可以告诉我们 **对指针加减会在内存中移动对应加减个步长** 

步长表示的是 指针当中存储类型的长度。比如
```c
int *  -> 步长是 int类型变量在内存当中的长度 也就是 4 
double * -> 步长是 double 类型变量在内存当中的长度 也就是 8 
char * -> 步长就是 char 类型变量在内存当中的长度 也就是  1
```
因此可以产生一个和我们遍历的想法类似的步骤。即
```C 
// 一般来说我们的数组可以采用如下的方式来进行遍历 
// 假定存在数组 arr 
for (int i = 0; i < sizeof(arr); i++){
    printf("索引%d 对应的值是%d\n",i,arr[i]);
}
```
```c
// 对应的如果我们利用上述规则，也就是通过移动指针来进行数组的遍历就会出现
#include <stdio.h>
int main(){
    int arr[4] = {1,2,3,4};
    int *p = arr;
    for (int i = 0; i < 4; i++) {
        printf("当前中对应数组的值是 %d\n",*p);
        p++;
    }
}
```
